## 项目与服务器

Atlas Automation Hub 是现有云服务器的实例名称，不是一个已有网站项目。本项目是该服务器上的独立 VPN 项目。

已核实当前主机为 `atlas-ewr`，本机公网出口与用户提供的实例截图一致，IP 地理信息返回美国。本项目仅使用这台 Atlas，不接入附件中的东京节点，也不新租服务器。

## 已确认需求

- 仅供本人使用，主要从台湾及其他海外地区连接。
- Netflix 美区内容实际可播放是硬性目标；美国 IP、网站可访问或隧道连接成功都不单独构成验收通过。
- 苹果设备使用 Shadowrocket；Windows 使用另一款兼容客户端。
- 按需手动开启，开启期间采用整机全局连接，不做按网站自动分流。
- 最小管理功能包括设备新增与停用、配置与二维码、最近连接时间、流量统计。
- 设备上的客户端负责连接开关；管理页不冒充设备端 VPN 开关。

## 技术起点

优先验证 WireGuard；Shadowrocket 支持该协议，Windows 候选客户端为 WireGuard 官方客户端。VLESS + REALITY 保留为另一个技术候选，不因附件使用它就默认部署。

固定 Atlas 出口时，切换隧道协议不等于改变出口 IP 的平台识别结果。Netflix 美区播放需要单独实测，当前没有播放成功证据。

## 实施顺序与验收

1. 核对现有主机网络、系统与云端端口规则，准备可恢复的独立部署。
2. 先建立最小连接并验证 Shadowrocket 与 Windows 客户端的实际连通性。
3. 检查 IPv4、IPv6 和 DNS 路径，确认预期互联网流量使用 Atlas 出口。
4. 测试前核对样本影片的当前地区可用性，选择非仅有全球授权内容的美区测试样本；同时核实账号套餐与播放画质条件。
5. 从用户实际设备与网络验证目标影片连续播放至少 10 分钟，没有地区或代理报错。画质尚未指定，先以 1080p 为初测目标，不据此宣称 4K 已通过。
6. 播放验收通过后，再实现最小管理页。未通过时记录具体结果，不将功能标记为满足 Netflix 美区要求。
